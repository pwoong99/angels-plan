# 엔젤스 플랜 😇

우리 반 두뇌 게임 대회 웹앱입니다. 학생들이 방에 들어오면, 선생님이 그때그때 게임을 골라 시작하고 점수와 순위를 겨룹니다. (탈락 없음, 하루 이벤트)

- 주소: https://pwoong99.github.io/angels-plan/
- Firebase: angels-plan 프로젝트 (보안 규칙은 firestore.rules)

## 공통
- 소개: 처음 들어오면 안내 천사 **포롱이**가 엔젤스 플랜의 취지를 소개 (건너뛰기 가능, 브라우저를 다시 열 때마다 한 번, 입장 화면에서 다시 보기)
- 캐릭터 그림: `img/porong-*.jpg` (Gemini로 만든 포롱이 — 진행·표정 6종)
- 관리자: 이름 칸을 비우고 관리자 비밀번호로 입장 → 관리자 겸 교사, [교사 승인]에서 등록 신청 승인·취소·삭제, 모든 방을 볼 수 있음
- 선생님: [선생님으로 등록하기]에서 이름·학교·비밀번호로 신청 → 관리자 승인 후 이름 + 비밀번호로 입장, 자기가 만든 방만 보고 관리
- 방: 방 번호 4자리, 방 바꾸기·메모, 예전 방 다시 쓰기
- 이 방에서 쓸 게임: 선생님이 [⚙️ 이 방에서 쓸 게임]에서 게임마다 켜기·끄기(방 문서 `off`). 끈 게임은 게임 고르기, 학생 연습 버튼, 게임 방법 버튼에서 빠짐(열려 있던 연습 창도 닫힘). 하나는 꼭 켜 두어야 하고, 지금 하는 게임은 끌 수 없음
- 학생: 방 번호 + 이름으로 입장 (같은 이름이면 이어하기)
- 팀: 2~6팀, 자동으로 나누기·카드에서 팀 바꾸기, 팀 점수 = 팀원 점수 평균
- 순위판: 개인 / 팀
- 오늘 점수 새로: 점수·팀·대결 기록 초기화 (방과 학생 명단은 그대로)

- 게임 설명: 선생님이 [게임 설명 시작] → 안내 천사가 장면마다 그림과 함께 규칙 설명, 선생님이 이전/다음으로 넘김 → 설명이 끝나면 스타트
- 나만의 천사: 처음 들어오면 캐릭터 만들기(얼굴형·피부색·눈·표정·머리 모양·머리색·옷 세트), 총 점수(새 이벤트를 해도 남는 점수)가 20·50·90·140·200·280·380점을 넘을 때마다 날개가 한 단계씩 자람(새싹 → 아기 → 솜털 → 반짝 → 큰 → 무지개 → 황금 → 전설)
- 선생님 화면: 학생 현황 옆에 점수 순위 목록, 팀은 팀 게임에서만 표시(팀별로 묶어서 보여 줌)

## 게임
### 🧩 울타리치기 (개인전)
- 슬리더링크 퍼즐. 연습 2단계(3×3) + 1~8단계(4×4~7×7), 단계마다 30문제 (정답이 하나뿐인지 검증)
- 점수: 맞히면 기본 10점 + 빠른 순서 보너스(1등 +5 … 5등 +1) × 단계 배율. 오답·시간 초과 0점
- 기다리는 동안 혼자 연습하기 (힌트 제공, 점수 없음)

### 🧱 벽바둑 1 (2~4명 대결)
- 선생님이 2·3·4명씩을 고르면 학생을 무작위로 조를 짬. 딱 나누어떨어지지 않으면 몇 조만 한 명 많거나 적게(2~4명) 짜서 부전승 없이 모두 참여
- 7×7 판. 2명: 말 4개(2개는 정해진 자리, 2개는 번갈아 직접 놓기) / 3~4명: 말 2개(1개는 정해진 자리, 1개는 거꾸로 순서로 직접 놓기)
- 차례: 말 하나를 꼭 1~2칸 이동(제자리 안 됨, 움직일 말이 하나도 없으면 차례가 저절로 넘어감) → 그 칸 둘레에 벽 1개. 서로 다른 색 말이 같은 공간에 없으면 끝, 내 말만 있는 공간 칸 수가 점수
- 한 수 제한 시간(기본 30초), 넘기면 자동으로 아무 곳에나 둠
- 점수: 1등(승리) 15 · 중간 등수·무승부 8 · 꼴찌(패배) 3
- 선생님 화면: 누가 누구와 대결 중인지, 진행 상태와 결과

### 🔷 벽바둑 2 (2~4명 대결)
- 벽바둑 1과 같은 판·벽·조 짜기·점수. 말이 두 종류: 네모(곧게 1~2칸, 꺾기 X) / 동그라미(꼭 2칸: 상하좌우로 한 칸 간 뒤 반드시 꺾어서 한 칸, ㄱ자로 대각선 칸에 도착. 지나는 칸에 벽·말이 있으면 그 길로는 못 감). 둘 다 제자리는 안 됨
- 2명: 네모 2 + 동그라미 2 (정해진 자리 하나씩, 직접 놓기 하나씩) / 3~4명: 네모 1(정해진 자리) + 동그라미 1(직접 놓기)
- 방송 규칙이 다 공개되지 않아 엔젤스 플랜용으로 정한 규칙 (`wallgo.js`의 `newMatch2`, `reachable`)

### 🦋 대칭 퍼즐 (개인전)
- 조금 복잡해 보이는 선대칭 도형을 늘 3조각으로 자른 문제. 조각을 옮기고(끌기) 돌려서(톡) 선대칭 모양 만들기. 뒤집기 X. 세로·가로·대각선 축 모두 인정, 겹치지 않고 모두 붙어 있어야 함
- 연습 2단계(7~9칸) + 1~6단계(9~21칸, 단계가 오를수록 칸 수와 울퉁불퉁함이 커짐), 연습 1은 12문제·나머지는 30문제(`sym.js`, 만드는 코드 `tools/sym_gen.py`). 문제마다 정답 예시가 있고 모두 검증됨
- 선대칭이 되는 순간 저절로 제출 → 먼저 완성한 순서대로 등수. 점수: 기본 + 순서 보너스 × 단계 배율(×0.5~×3)
- 제한 시간 30초씩 조절 또는 ♾️ 제한 없음. 끝나면 정답 예시

### 🔍 달라진 그림 찾기 (개인전)
- 원래 그림과 바뀐 그림을 나란히(세로 화면은 위아래로) 보고 다른 곳을 톡. 맞으면 ⭕, 틀리면 ✕와 1.5초 쉬기. 🔍 크게(2배·3배) 보고 끌면 두 그림이 함께 움직임
- 그림 세트: 제미나이로 만든 원본 1장 + 쉬움·보통·어려움 3장(`img/spot/`). 세트 난이도 ⭐(가까이서 본 작은 장면) ~ ⭐⭐⭐(멀리서 본 넓은 장면)
  - 지금 세트: 1 빵집 진열대·2 바닷가 모래밭(⭐), 3 교실·4 숲속 캠핑(⭐⭐), 5 큰 공원(⭐⭐⭐)
- 단계 9개 = 세트 난이도 3 × 그림 난이도 3. 같은 단계에 세트가 둘이면 아직 안 나온 그림이 나감. 배율 ×0.6~×1.5
- 다른 곳 위치(`spot.js`): 원본과 바꾼 그림을 픽셀 비교해 찾고 사람이 확인해 다듬음
  - 새 세트 넣기: PNG를 한 폴더에 `setN_original/easy/normal/hard.png`로 모으고 `python3 tools/spot/diff.py 60 10 300 폴더` → `tools/spot/check_auto/`의 그림을 보고 `build.py`의 FIX(합치기·더하기)를 고침 → `python3 tools/spot/build.py 폴더` → `python3 tools/spot/make_js.py`. 새 세트는 `tools/spot/spot_template.js`의 `SPOT_SETS`에 이름·별 개수 추가
- 모두 찾으면 저절로 제출 → 먼저 찾은 순서대로 등수 보너스. 일부만 찾으면 기본 점수 × 찾은 비율 × 배율(최소 참여 점수)
- 제한 시간 30초씩 조절 또는 ♾️ 제한 없음. 끝나면 학생은 내가 찾은 곳(초록)·못 찾은 곳(주황), 선생님은 [다른 곳 보기]

### 🧊 큐브 세기 (개인전, 한 판 5문제)
- 쌓기나무처럼 쌓인 큐브가 모두 몇 개인지 세기. 보이지 않는 아래쪽 큐브도 셈(공중에 뜬 큐브 없음)
- 연습 2단계 + 1~8단계(바닥 2×2~6×5, 최대 2~5층), 단계마다 40문제. 모든 기둥의 윗면이 보이는 문제만 골라 둠(`cubes.js`)
- 답(큐브 개수)이 최대한 겹치지 않게 고름(`tools/cubes_spread.py`): 5~8단계는 40문제 답이 모두 다르고, 1~4단계는 같은 답이 2~3개까지. 한 판 5문제는 답이 서로 다르고, 앞 판에서 나온 답은 되도록 피함
- 선생님이 단계·제한 시간(5문제 전체, 10초씩 조절 또는 ♾️ 제한 없음)을 고르고 스타트 → 그 방에서 아직 안 나온 문제 5개가 모두에게 똑같이 나감
- 숫자 버튼으로 답 → 확인하면 다음 문제(고칠 수 없음). 새로고침해도 푼 데까지 이어짐
- 점수: 5문제 모두 맞히면 기본 점수 + 끝낸 순서 보너스 × 단계 배율, 일부만 맞히면 기본 점수 × 맞힌 비율 × 배율
- 제한 없음: 지난 시간만 보이고 시간 초과 없음. 모두 다 풀면 자동 종료, 아니면 선생님이 [라운드 끝내기] → 그때까지 푼 문제만 채점(다 맞힌 학생은 끝낸 순서대로 등수 보너스)
- 끝나면 학생·선생님 화면에 문제별 정답(학생은 내 답 ⭕❌)

## 혼자 연습

- 달라진 그림 찾기: 모든 단계 그림, 정답 보기

## 새 버전 올리기
`python3 tools/bump.py v1.6` — 화면의 버전, 파일 주소의 `?v=`, `version.json`을 한 번에 바꿈.
앱은 3분마다 `version.json`을 확인해서 새 버전이 있으면 첫 화면에서는 저절로, 게임 중에는 알림 띠로 새로고침을 권함.
